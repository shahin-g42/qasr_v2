-------------------
 NOTES
-------------------

- Global batch size: 32 GPUs x 4 per_device x 1 accum = 128
- Projector stage: 5,000 steps, LR 1e-4, encoder+LLM frozen
- Full stage: 500,000 steps, LR 2e-5, all parameters trainable
- DeepSpeed ZeRO-3, BF16, TF32, SDPA attention, gradient checkpointing
- Augmentation: SpecAugment + SpeedPerturb + NoiseInjection + CodecAugment (p=0.37)
- Master node hostname: update "inception-H100-hpc-008" to your actual master
- All nodes must share the same filesystem (lustrefs)
- Ensure NCCL InfiniBand is available for inter-node communication
- Set NCCL_DEBUG=INFO for debugging connectivity issues


================================================================================
PHASE 3: EAGLE-2 SPECULATIVE DECODING HEAD (Optional - Inference Acceleration)
================================================================================

After Phase 2 (full fine-tuning) completes, train the EAGLE-2 draft head for
2-3x faster inference. This trains only ~8.4M parameters on a frozen QASR
checkpoint using KL-divergence against the target model's logits.

Expected time: ~2-5 hours on 8 GPUs (single node, 10,000 steps).
Expected speedup: 2-3x decode throughput, ~200ms faster partials in streaming.

--- Option A: SLURM (single node) ---

    sbatch scripts/qasr_train_eagle.slurm

--- Option B: Manual (single node, 8 GPUs) ---

    PYTHONPATH=src torchrun \
      --nnodes=1 \
      --nproc_per_node=8 \
      --node_rank=0 \
      --master_addr="127.0.0.1" \
      --master_port=29501 \
      --rdzv_backend=static \
      train_eagle.py --config configs/train_eagle_8node_filtered.yaml

--- EAGLE Training Parameters ---

    Model:          frozen QASR checkpoint from Phase 2
    EAGLE head:     FC(4096,2048) over concat(h_t, embed(x_{t+1})) + SiLU +
                    LayerNorm + residual, then frozen FC(2048,151936) lm_head
    Parameters:     ~8.4M trainable (vs 1.7B for full model)
    Steps:          10,000
    Batch size:     32 per GPU × 8 GPUs = 256 global (config sized for
                    64 GPUs = 2,048; see scripts/qasr_train_eagle_8node.slurm)
    Learning rate:  3e-4 (cosine, 200 warmup)
    Loss:           KL-divergence (draft || target logits)
    Output:         /lustrefs/shared/shahin.konadath/workspace/train/stt/qasr/output/eagle_v3

--- Using EAGLE for Inference ---

    # CLI inference with speculative decoding:
    PYTHONPATH=src python inference.py audio.wav \
      --model /lustrefs/shared/shahin.konadath/workspace/expmt/qasr/full \
      --eagle /lustrefs/shared/shahin.konadath/workspace/expmt/qasr/eagle \
      --num-draft-tokens 5

    # Streaming server with speculative decoding:
    PYTHONPATH=src python -m qasr.server \
      --model /lustrefs/shared/shahin.konadath/workspace/expmt/qasr/full \
      --eagle /lustrefs/shared/shahin.konadath/workspace/expmt/qasr/eagle \
      --port 8765

--- Full Training Pipeline Summary ---

    Phase 1: Projector    → 5,000 steps   → projector/checkpoint-5000
    Phase 2: Full         → 500,000 steps → full/checkpoint-500000
    Phase 3: EAGLE head   → 10,000 steps  → eagle_v3/eagle_head.pt

    Total GPU-hours: ~2,500 (Phase 1+2) + ~30 (Phase 3)
    Inference speedup from EAGLE: 2-3x decode throughput
